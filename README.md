# KickDuck

**KickDuck** — стерео-плагин сайдчейн-дакинга в формате VST3 для Linux. Сделан для классического эффекта «насоса»: бас или пад вычитается в такт бочке. Работает в двух режимах — классическая компрессия по сайдчейну (COMP) и Kickstart-подобный режим с фиксированной кривой по длине ноты (KICK).

## Возможности

- **COMP-режим** — компрессорный дакинг по сигналу сайдчейна: Threshold, Ratio, Attack, Release, Knee.
- **KICK-режим** — фиксированная кривая дакинга, синхронная с темпом проекта: длина задаётся нотами от 1/64 до 4/4, форма провала — параметром Shape.
- **Двойной драг по графику** — вертикальное перетаскивание меняет глубину дака, горизонтальное — длину дака (KICK) или релиз (COMP).
- **Редактируемая кривая дакинга** — в KICK-режиме поверх графиков рисуется идеальная кривая; тяните кружок в её середине вверх/вниз, чтобы менять форму (Shape).
- **Замирающий осциллограф** — график привязывается к началу дака и держит кадр неподвижно, пока идёт следующий удар.
- **Пресеты** — пять заготовок: Kickstart Pump, Gentle Sway, Trance Gate, Comp Glue, Bass Killer.
- **Измерители уровня** — вход и выход с пиковым удержанием.
- **Mix** — параллельный (компенсационный) микс обработанного сигнала.
- **Сайдчейн-вход** — отдельная стерео-шина для триггера; в COMP-режиме на неё навешивается НЧ-срез (HPF), чтобы триггерить по басу, а не по вокалу.
- **Сохранение состояния** — все параметры пишутся в проект DAW.

## Требования

- Linux x86_64
- CMake 3.22 или новее
- Компилятор с поддержкой C++17 (GCC 9+, Clang 10+)
- JUCE 7 или 9 (как git-подмодуль или распакованный архив)

## Сборка и установка

```bash
cd ~/Temp/KickDuck

# конфигурация (один раз)
cmake -B build -DCMAKE_BUILD_TYPE=Release

# сборка
cmake --build build --config Release
```

После сборки плагин появится в:

```
build/KickDuck_artefacts/Release/VST3/KickDuck.vst3
```

Установить в систему:

```bash
cp -r build/KickDuck_artefacts/Release/VST3/KickDuck.vst3 ~/.vst3/
```

После этого перезапустите DAW (Reaper, Bitwig, Ardour и т. д.) — плагин появится в списке как **KickDuck**.

### Сайдчейн-подключение

В DAW направьте канал с бочкой в сайдчейн-вход плагина:

- **Reaper** — на треке с KickDuck включите «Send source to sidechain input», выберите источником трек с бочкой.
- **Bitwig** — в панели плагина назначьте «Sidechain» на нужный трек.
- **Ardour** — добавьте на трек с KickDuck аудио-подключение с трека бочки на вход «Sidechain».

Если сайдчейн не подключён, COMP-режим триггерит по самому обрабатываемому сигналу, а KICK-режиму сайдчейн не нужен вовсе.

## Режимы работы

### COMP (компрессорный дакинг)

Классический сайдчейн-компрессор. Когда уровень сайдчейна превышает порог, усиление плавно снижается до глубины не более, чем Max duck, и восстанавливается после спада.

| Параметр | Диапазон | Описание |
|---|---|---|
| Thr | −60…0 дБ | Порог срабатывания |
| Ratio | 1:1…20:1 | Степень сжатия |
| Atk | 0.1…100 мс | Атака огибающей детектора |
| Rel | 5…1000 мс | Восстановление |
| Knee | 0…24 дБ | Мягкость колена |
| Max duck | 0…24 дБ | Максимальная глубина дака |
| Mix | 0…100 % | Баланс сухого и обработанного |
| SC HPF | 20…2000 Гц | НЧ-срез сайдчейна |
| Out | −12…+12 дБ | Выходная громкость |

Горизонтальный драг по графику в этом режиме управляет **Release** — удобно подстраивать время восстановления под темп.

### KICK (Kickstart-режим)

Дакинг не по уровню, а по времени: на каждую долю такта усиление проваливается до Max duck и по фиксированной кривой возвращается за длину, заданную в нотах. Кривая полностью синхронна с транспортом DAW.

| Параметр | Диапазон | Описание |
|---|---|---|
| Len | 1/64…4/4 | Длина дака в нотах |
| Shape | 0.5…8 | Форма кривой: меньше — ровнее провал, больше — резче атака и плавнее хвост |
| Max duck | 0…24 дБ | Глубина провала |
| Mix | 0…100 % | Баланс |
| Out | −12…+12 дБ | Выходная громкость |

Если транспорт не играет, кривая тикает свободно на темпе проекта (по умолчанию 120 BPM).

Перетаскивание по графику: **вертикаль** — Max duck, **горизонталь** — длина дака. Пунктирные направляющие показывают текущие значения, а кружок на кривой дакинга тянет Shape.

## Управление графиком

- **Замирание кадра.** Когда график «схватил» начало дака, окно фиксируется: точка старта дака всегда стоит на 20 % ширины экрана, и вы видите полный цикл провала и восстановления. Если дака нет — график работает как обычная бегущая строка.
- **Кнопка IN/OUT** — переключает отображаемую волну: вход (Bass) или выход (Ducked).
- **Цвета:** синий — сигнал, оранжевый — метки ударов/сайдчейн, зелёная сплошная — реальное снижение усиления, зелёная полупрозрачная — идеальная кривая дакинга.

## Пресеты

| Пресет | Режим | Назначение |
|---|---|---|
| Kickstart Pump | KICK | Классический клубный «насос», 1/2 такта |
| Gentle Sway | KICK | Мягкое покачивание под бочку, 1/4 |
| Trance Gate | KICK | Резкое пульсирование, 1/8 |
| Comp Glue | COMP | Лёгкая склейка и управление динамикой |
| Bass Killer | COMP | Агрессивное вычитание баса под кик |

## Известные особенности

- Длина дака отсчитывается от последней доли, поэтому при значении больше доли (например, 2/4 в размере 4/4) провал перекрывает соседние удары — это поведение Kickstart, оно штатно.
- В ворнингах сборки сообщения от исходников Opus внутри JUCE (`-Wstringop-overflow=`, устаревший `juce::Font (float, int)`) — это шум от стороннего кода и старого API, на работу не влияет.
